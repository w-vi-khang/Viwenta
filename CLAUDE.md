# CLAUDE.md

Common rules, skills and hooks come from the `ai-workflow-kit` plugin (declared in `.claude/settings.json`).
This file holds only information SPECIFIC to this project.

- Verification config: @.ai/project.json
- Project rules (if any): @AGENTS.local.md

## Architecture overview
Unity 6000.4.8f1 voxel game. All project content lives in Assets/_Project/
(Scenes, Scripts, Prefabs, Materials, Art). Only built-in modules are installed
(Packages/manifest.json); there is no test framework or CI yet.
Library/, Logs/ and UserSettings/ are generated by the Editor and not committed.
